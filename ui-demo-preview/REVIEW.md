# 领导版设计评审

状态为等待用户批准。没有修改正式工作台代码、诊断 Prompt 或开始新录制。现有旧版视频保留，不冒充这版设计的演示。

本次交付五屏静态 SVG mockup 和离线可点击评审页。页外可切换场景、保留或建议修改/删去、写意见并导出。画内业务按钮是示意，不是实际操作入口。

领导版关注业务影响、处理优先级、原因可信度、独立解决路线、投入与风险、授权取舍和结果留痕。不展示技术命令、代码、错误码或逐步排障指南。

五条路线分别为定点修复、恢复稳定版本、切换备用服务、人工受理和隔离重建。它们是备选方案，不是步骤一至五。人工受理解决的是业务连续性，不冒称修好了系统。推荐有适用前提，时间和资源未知时注明待评估。

场景内容全部是演示情景。示意中的上一稳定版本可用是设计假设，不是对真实事故的调查结论。

按领域建模原则，把事实、推测、方案选择、执行授权和处理结果分开。按真实验证原则，实际检查五屏切换、刷新保留意见、JSON 导出、键盘操作、页面溢出和 SVG 文字几何范围，均通过。没有截屏、生成图片或录制视频。

批准之后，再把领导版表达应用到正式工作台并验证，然后按已批准分镜录制新演示。设计评审中的“保留此屏”不构成任何业务执行授权。

重建命令为 `python3 build_review.py`，验证命令为 `python3 verify.py`。这些命令仅影响此设计评审目录。
